Card commands

Lower-level command objects are useful when an app needs explicit control after scan() returns a connected transport. They are open classes; see Subclassing.

let commands = UltralightCommands(transport: transport)
let pages = try await commands.readPages(startPage: 4)
try await commands.writePage(4, data: Data([0x01, 0x02, 0x03, 0x04]),
                             memoryMap: UltralightMemoryMap.forType(info.type))

let desfire = DESFireCommands(transport: transport)
let version = try await desfire.getVersion()
let aids = try await desfire.getApplicationIDs()

let select = CommandAPDU.select(aid: passportAID)
let response = try await iso7816Transport.sendAPDU(select)
if response.isApplicationNotFound { /* the card does not carry this AID */ }

let security = ISO15693SecurityManager(transport: iso15693Transport)
try await security.configureAFI(0x01, permanentlyLock: false)

Ultralight / NTAG write guard

UltralightCommands.writePage(_:data:memoryMap:allowIrreversible:) and compatibilityWrite(_:data:memoryMap:allowIrreversible:), and the top-level CoreExtendedNFC.writeUltralightPage and compatibilityWriteUltralightPage, refuse writes that may be irreversible unless allowIrreversible is true. Pages 0-2 (UID and static lock bytes) are always refused. Page 3 (OTP / Capability Container) bits can only be set, never cleared, so the library reads page 3 first and allows the write only when it would change nothing; writing a new CC needs allowIrreversible: true (or formatNDEF, which opts in). With a memoryMap, every page outside the product's user data area (dynamic lock, CFG, PWD/PACK, Ultralight C key pages) is refused too. Without one, UltralightCommands checks pages 0-3, and the top-level writeUltralightPage / compatibilityWriteUltralightPage also refuse every page above 15. The 1.x names CoreExtendedNFC.writePage / compatibilityWrite are deprecated forwarders with the same guard. A refused write throws NFCError.irreversibleWriteRefused(page:) before anything is sent; malformed arguments throw invalidParameter. WRITE and COMPATIBILITY_WRITE require the 0x0A ACK; an empty response is a failure. UltralightDump.restore validates every page (4 bytes, matching card type) before writing. allowIrreversible: true can permanently lock or brick the tag.

ISO 15693 security

ISO15693SecurityManager.configureAFI(_:permanentlyLock:) and configureDSFID(_:permanentlyLock:) write the value, and send LOCK AFI / LOCK DSFID only when permanentlyLock is true. That lock is irreversible. The older lock: overloads are deprecated. The facade range functions readISO15693Blocks(range:transport:) and getISO15693BlockSecurityStatus(range:transport:) take a ClosedRange<Int> such as 0...3 and throw NFCError.invalidParameter for bounds outside 0...255 before anything is sent; the NSRange overloads are deprecated. ISO15693Reader.readBlock(at:) and writeBlock(at:data:) use the extended commands for blocks from 256 on, and readAllBlocks(info:) replaces the deprecated readAllBlocks(transport:). ISO15693SystemInfo.dsfid, afi and icReference are optional and are nil when the tag does not report them. Tag error codes 0x12 / 0x14 (block locked) are thrown as NFCError.tagLocked; other ISO/IEC 15693-3 error codes are thrown as NFCError.iso15693Error(code:).

DESFire

getVersion() maps the hardware major version to EV1 (0x01), EV2 (0x12, 0x22, 0x42) or EV3 (0x33). File settings include Transaction MAC files (type 0x05). The library has no DESFire write API. The automatic dump reads every free-access file and keys each one by AID (3 bytes) ‖ file ID (1 byte), so equal file IDs in different applications stay distinct. Applications and files that need authentication are skipped and counted. Transaction MAC files are counted but not read.

APDUs

CommandAPDU encodes short APDUs, and switches to extended length automatically when the command data exceeds 255 bytes or more than 256 response bytes are expected (Nc up to 65535, Ne up to 65536). APDUExchange.transmit(_:maxGetResponseFrames:retryOnWrongLength:using:) resolves 6Cxx (re-issue with the corrected Le) and 61xx (GET RESPONSE chaining). It throws NFCError.responseChainTooLong(maxFrames:) after defaultMaxGetResponseFrames (256) follow-ups.

Type 4

Type4Reader is the Type 4 entry point; Type4Tag is deprecated and forwards to it. Type4CC parses both the NDEF File Control TLV (T4T 2.0, 2-byte NLEN) and the Extended NDEF File Control TLV (T4T 3.0, T = 06h, 4-byte ENLEN). maxNDEFFileSize carries the full size, and ndefLengthFieldSize is 2 or 4. Writes split the length header by MLc and refuse NDEF files larger than 32 KB. UPDATE BINARY answered with 6982 / 6985, or a CC that denies write access, throws NFCError.tagLocked.

ATQA 0344 (7-byte UID) or 0304 (4-byte random ID) with SAK 20 is classified as DESFire. Any other ATQA with SAK 20, and SAK 28 / 38 (ISO 14443-4 with Classic emulation), is reported as .smartMX, a generic ISO 7816 card that refineCardInfo probes for DESFire, Type 4 and eMRTD. Refinement also detects Ultralight C (a 16-byte answer to READ 2B, no authentication attempted), NTAG210/212 from GET_VERSION, and FeliCa Lite vs Lite-S on system code 88B4 (only Lite-S answers a read of block 0x90).
