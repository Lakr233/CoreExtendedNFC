Errors

Every failure the library throws is an NFCError. It is Sendable, Equatable and a LocalizedError with localized descriptions, so apps can match on cases instead of message text.

Cancellation

do {
    let (info, dump) = try await CoreExtendedNFC.scanAndDump()
} catch where error.isNFCCancellation {
    // User dismissed the sheet, task cancelled, or the app ended the scan: stay silent.
} catch {
    showAlert(error.localizedDescription)
}

Error.isNFCCancellation is true for NFCError.userCanceled, CancellationError and NFCError.sessionInvalidatedByCaller. NFCError.isUserCancellation is true only for .userCanceled. After the user dismisses the sheet, later session-loss failures from that session's transports are reported as .userCanceled. NFCSessionManager.wasCanceledByUser covers a failure that raced the cancel.

invalidParameter(String)An argument is out of range or malformed, for example a DESFire AID that is not 3 bytes.
malformedDump(String)A memory dump being exported or imported is malformed or inconsistent.
